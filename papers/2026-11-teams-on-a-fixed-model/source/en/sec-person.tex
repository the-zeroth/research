\section{Working with a Person}
\label{sec:person}

Benchmarks give the agent a complete task once; a person corrects it, comes back later, and expects
it to remember. Four product benches measured that side (\cref{tab:benches}). Their results point
the same way as the coding work: what travels is written down where the next agent will read it,
not held in a memory tool.

Two results changed the design. The assistant kept every habit because it rewrote the person's
words into each brief; teams kept them only when the words reached a file they read. And no agent
in 104 sequenced tasks called the memory tool on its own, so standing rules now live in files the
next agent reads, and lessons are left to the work's own files and the assistant's briefs.

One line of work found nothing to ship. Eight rounds of an ``evolution lab'' (\$59.55 in model
cost) chased a miss that came mostly from our own task summary: with the summary fixed, the shipped
team solved the task 4 of 4 times against 3 of 21 before.
