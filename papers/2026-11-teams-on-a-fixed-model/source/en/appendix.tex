\section{Reproducing the Terminal-Bench 4.1 Run}
\label{app:repro}

The dataset was Terminal-Bench~4.1 at AA's digest, downloaded with Harbor 0.26.0:
\begin{center}
\code{terminal-bench/terminal-bench@sha256:39d9f44b\ldots e27732}
\end{center}
With an OpenAI API key, the public adapter \citep{zhang2026adapter} runs it as follows:

\begin{small}
\begin{verbatim}
git clone https://github.com/the-zeroth/the-one-harbor
export OPENAI_API_KEY=...
PYTHONPATH=the-one-harbor/scripts/harbor \
  uvx --python 3.12 --from harbor==0.26.0 harbor run \
  -p <dataset folder> -n 30 -k 3 \
  -a the_one_server_agent:TheOneServer -m openai/gpt-6.2-sol --effort max \
  --ak version=0.5.2 --ak run_timeout=465m
\end{verbatim}
\end{small}

\code{--ak version} pins the server release, and \code{--ak run\_timeout} sets how long the team may
work; the server's own default is 3 hours, which cuts long tasks short. Our run differed in three
ways: it used the product's ChatGPT (Codex) sign-in through a credentials file instead of an API
key, it ran as two jobs of 15 concurrent trials (readable and held-out tasks), and it left out the
three GPU tasks. Harbor 0.24 has no \code{--effort} option; pass \code{--ak reasoning\_effort=max}
instead.
