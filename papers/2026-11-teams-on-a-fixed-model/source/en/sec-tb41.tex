\section{The Final Configuration on Terminal-Bench 4.1 (RQ4)}
\label{sec:tb41}

The One 0.5.2 with team 7.0 on GPT-6.2 Sol at max effort scored 60.9\% on the 63 tasks we could
run and 58.1\% over all 66 with the three GPU tasks counted as zero. That ties Codex on the same
model and effort in AA's run (58.1\%) and sits within noise of the Terminal-Bench maintainers' run
of it (61.5\%).

\para{Setup} Harbor 0.26.0 at AA's dataset digest; the published server 0.5.2 installed in each
task container; GPT-6.2 Sol at max effort through a ChatGPT sign-in; three attempts per task,
matching AA's protocol, 30 at a time on one Linux PC without a GPU; Terminal-Bench's 8-hour agent
timeout honoured. Two held-out attempts died downloading the server before the agent started; they
were re-run, as the Terminal-Bench maintainers re-run infrastructure errors, and scored 0 again.
Against our Terminal-Bench~4.0 copy, only one task differs in 4.1.

\para{Against the boards} AA reports tokens per benchmark but cost and time only per agent across
all its benchmarks, so we priced its Codex rows ourselves at the same list prices
(\cref{tab:cost}). Codex on GPT-6.2 Sol at max used 4.48M input and 51k output tokens per attempt,
about \$1.42 at list price; we used 30\% fewer input tokens for \$1.35. Codex on GPT-6.2 Astra at
max scored 63.6\% at about \$5.04 per attempt. The maintainers' own board for 4.1, five trials on
each of the 66 tasks, lists Codex on GPT-6.2 Sol at max at 61.5\% and Codex on GPT-6.2 Astra at max
at 62.1\% \citep{tbench2026board}. The top rows of both boards come from Claude, Gemini and Kimi
agents and from a multi-model agent, GitHub Copilot's Copilot Fusion (71.2\% on the maintainers'
board).

\para{Earlier, on Terminal-Bench~4.0} With the same split, the configuration scored about 38 of 63
on GPT-6.1 Sol and about 39 on GPT-6.2 Sol, against public board trials of Codex 0.159 with GPT-6.1
Sol (36.4) and Claude Code 2.1.284 with Claude Opus 5.5 (39.8). On the unread half our GPT-6.1
configuration led Codex by $+1.23$ (95\% interval $-0.30$ to $+2.77$ over six draws). Claude Code's
lead on the readable half came from seven open-reading tasks it passed 34 of 35 times. Per trial
at list price, ours cost \$1.37 on the unread set against \$1.51 for Codex and \$11.39 for Claude
Code. The first full baseline (31 October, the team shipped at the time, at medium effort, on the
Mac) had passed 29 of 63.

\para{SWE-Atlas-QnA} On the 124-question set \citep{raghavendra2026sweatlas} (29 October, GPT-6.1 Sol
at medium effort, the team of the time), AA's rubric grader met 58\% (70 of 120 graded questions)
and the Scale rubric grader 52\% (62 of 120), at a median 9.5 minutes and \$0.42 a question; AA
listed Codex with GPT-6.1 Sol at max at 60\%. Of 101 unmet rubric items, 44 asked for evidence from
running the software. A question checker ($+5$ against a pre-registered gate of $+6$, at 1.45 times
the cost) and a high-effort lead ($-2$, at 1.57 times) were not kept.

\para{Reward-hacking scan} AA's 4.1 audit reads every passing attempt and scores answer lookups,
test edits and solution access as 0 \citep{aa2026coding}. Our scanner reads each attempt's
trajectory for network calls that name the benchmark, a task or its upstream source, and for any
read, listing or write of a grading path (tests, solution, verifier logs, reward files). It found
no such network call in any attempt, and no read, listing or write of a grading path. On the
held-out side, two passing attempts of one task wrote file contents that mention the verifier's log
folder; those trajectories are held out, so we have not judged them.

\para{Answer to RQ4} On a fixed frontier model, the harness reaches the vendor's own agent and makes
it cheaper in tokens, but it does not yet beat it.
