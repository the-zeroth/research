Teams on a Fixed Model: Two Months of Harness Experiments with The One (preprint, November 2026)

Build (XeLaTeX via Tectonic; BibTeX runs automatically):
  tectonic -X compile main.tex
With TeX Live instead: xelatex main && bibtex main && xelatex main && xelatex main

Files: main.tex (preamble, title, abstract), sec-*.tex (sections), appendix.tex,
refs.bib (bibliography), main.bbl (pre-built bibliography, for arXiv).
Fonts: TeX Gyre Termes, TeX Gyre Termes Math, TeX Gyre Heros, Inconsolata (all in TeX Live).
