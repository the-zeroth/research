# Working groups · 工作组

Research notes on The One's working groups: agent teams built for one kind of real work each, measured on jobs the
company had already finished. Each note records what we tried, in order, what it measured, what shipped and what
did not. Negative results are kept.

The One 各工作组的研究记录。每个工作组是为一类真实工作搭建的智能体团队，用公司已经完成过的真实任务来衡量。
每篇记录按时间顺序写清做过什么、量出了什么、哪些上线、哪些没有上线，负面结果一并保留。
