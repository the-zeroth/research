# 前端设计组

[English](frontend-design.md) · [全部工作组记录](README.md) · [研究方法](method.zh.md)

要回答的问题是：在固定模型（GPT-6.2 Sol）之上，一个智能体团队能否做出既有创意、完成度又高的网页，
达到 Awwwards 当日最佳（Site of the Day）或年度最佳（Site of the Year）获奖网站的水平？
这份记录按时间顺序写下 2026 年 11 月 23 日至 27 日我们试过的做法，也包括负面结果。

The One 里有两个团队做网页。`frontend_design_studio`（一名总监、一名实现者和一名审查者）是专门的工作组。
默认领队（一个方案领队，加上它可以启动的帮手）承接主助手分派来的大部分网站工作。两个团队我们都做了测量。

## 任务

- **工作组的题单**：公司已经完成过的十五项前端工作（产品的页面和公司网站的页面），其中五项按带种子的随机抽签留出。
  程序检查：页面能构建、能打开；在 390、1024 和 1440 像素宽度下都没有横向滚动；
  文字的对比度和字号都不低于下限；题目给出的事实都在页面上。
- **竞赛题**，只用于测量：js13kGames 2026；EuroSkills 2025 网页开发项目的模块 A 和模块 D，按官方评分方案打分；
  以及三道为虚构客户出的题，客户类型与三个 2025 年 Awwwards 获奖网站相同：
  一位赛车手的网站（获奖网站：Lando Norris，OFF+BRAND 制作，年度最佳）、
  一个电动越野品牌的发布网站（Scout Motors，Locomotive 制作，年度最佳电商网站），
  以及为一家快递公司做的交互式 3D 作品（Messenger，abeto 制作，年度最佳开发者网站）。
  我们从未使用这些获奖网站的素材，也从未发布它们的截图；它们只在本地截图，作为评委比较时的标杆。
- **新题**，为这项研究编写，不以任何获奖网站为蓝本：一家提供订阅的酸种面包店、一个为期十天的舞蹈节，
  以及一个开源时序数据库的 1.0 版发布。在获奖对照题上有用的改法，在这里也必须有用。

## 第一阶段（11 月 23–24 日）：工作室对比默认领队

- 在程序检查上，两个团队相差不大（8 道题中分别通过 7 道和 6 道）；工作室更快。
- 在创始人对第一轮的盲评中，默认领队在 9 组对比中赢了 7 组。
  两者都远不及获奖网站：没有自己的创意，也没有任何会动的东西。
- 在竞赛题上：默认领队在 EuroSkills 模块 D 上得到 22 分中的 21.00 分，与金牌得主的分数相同（参赛选手平均 10.09 分）；
  工作室在模块 A 上得到 16.5 分中的 14.17 分（中位数 12.94，金牌 15.66）。
- 工作室落后的原因：工作室的每个角色都跑在中等推理强度的能力槽上，
  而领队跑在最高推理强度的编码能力槽上（在一道题上，推理 token 是 2,475 对 18,055）。
  工作室 2.1 版把总监和审查者放到规划能力槽，把实现者放到编码能力槽。创始人在第二轮没有看到质的变化。
- AI 评委加入了创始人的评审：新启动的 Claude Opus 智能体在同样的盲评条件下拿到题目文本和截图，
  在 3 道题上全部与创始人选得一样，只是打分向中间压缩。

## 第二阶段（11 月 24–25 日）：先用代码做视觉，再用生成图像

- **只用代码就能渲染出获奖级别的视觉**。在三个与题目无关的题材上（一块手表、黎明时的海岸、一个品牌的动态循环），
  默认领队只用代码做出了主视觉静帧和循环动画：以 Python 模块方式调用 Blender、用 Cycles 渲染，
  或在 CPU 渲染器上运行 OpenGL 着色器，用时 32 到 77 分钟；用 Cycles 渲染的手表达到了照片级。
  同样题材的实时 three.js 版本要弱一些（没有反射，材质像塑料）。此前的网站任务从未要求过这类工作。
- **艺术总监的意见有用；选择才是瓶颈**。每一轮意见都让画面变好，而大的跃升只来自改变方向的意见；
  团队自己的批评只在最初的方向内打磨。要求给出三个不同方向时，团队画了三个草稿，每次都挑了最常规的那个。
  来自团队之外、选定方向的一句话，胜过两轮意见。所以上线的技能是：渲染三个方向，请用户挑一个，再按挑中的方向做。
- **放到整站上，挑选的效果显不出来**。同一个网站在不同轮次之间的评委分数相差约 3 分，大于选方向这一改法的效果。
  我们做了校准：获奖网站用同样的方式截图，作为参照条目一起展示；每轮两位评委，对每个条目的打分相差在 0 到 2 分之内。
- 一条让首屏画面动起来的规则，在 6 个作品中的 2 个里增加了动态，每道题约提高 0.7 分（属于噪声）；没有上线。
- **图像生成**。通过图像生成插件（一条 OpenRouter 线路），只要连接已就绪，领队就会生成照片素材（没有连接时从不生成）；
  凡是这样做了的题目，评分每题提高 1.25 到 1.75 分，但仍比获奖网站低 1 到 3 分。
  一张静帧还可以拍成一段短循环，用在首屏画面上。创始人认为生成图像明显更好；这个插件已经发布。

## 第三阶段（11 月 26–27 日）：只用代码做创意

创始人 11 月 26 日定下的方向：没有图像或视频模型的场景优先；我们的作品离获奖网站很远，差距不是一两分；
要把创意这一面做起来，让结果不再雷同；只用 GPT Sol。

### 怎样评判

每个评判文件夹里有题目、每个作品在 1440 和 390 像素下的截图，以及一次*试玩*：
脚本移动鼠标、按住、点击、拖拽、按键、滚动和等待时截下的十二帧画面，每帧都标注了屏幕上发生变化的部分所占的比例。
获奖网站也用同样的方式试玩和截图。一位创意优先的评委在打任何分之前，先为每个条目写下：
用一句话写出的创意（“访客在这里[做什么]，因为[这一点真实]”），或者写“无”；
页面是不是它所属类别的默认形态（即*模板*：大字号的名字放在主体的物件旁边，接着一条事实栏，
再往下是一节节堆叠、依次淡入的板块）；换上竞争对手的名字，这个创意是否依然成立（即*移植测试*）；
访客会讲给朋友听的那个瞬间；一位当天看过三十个网站的评委，一周后是否还记得它；以及它能否拿到当日最佳。
然后是 Awwwards 的四项评分（设计 40%、可用性 30%、创意 20%、内容 10%），每项 1 到 10 分。

第一次校准（第 11 轮）：获奖网站 31.6 分（满分 40），我们的作品 24 到 26 分；
没有一次评阅认为我们的作品有自己的创意；所有作品都是同一种构图；生成图像提高了完成度，但没有提高创意。

### 打动了评委的改法

| 改法 | 改了什么 | 测量结果 |
| --- | --- | --- |
| 独立的头脑 | 领队启动三个概念智能体，它们既看不到领队的草稿，也看不到彼此，每个各拿主体的一个真实事实；每个写一个由访客来完成的创意，并且只为它的招牌瞬间做原型 | 创意分比对照组 +1.6，总分 +1.8；12 次评阅中 12 次认为创意只属于这个客户（让一个头脑想三个创意时，它把同一个创意写了三遍） |
| 原型优先 | 把选中的原型复制进来作为首屏再修改，从不在空白页面上重做 | 新题：创意分比对照组 +2.4，总分 +3.4；12 次评阅中 6 次判为能拿当日最佳（对照组 0 次） |
| 手放在主体上 | 指针直接作用于主体本身，指针一动，立刻有看得见的变化；主体占满屏幕，文字以小字号放在它的边缘 | 获奖对照题：创意分 7.00 对 5.49；12 次评阅中，一周后还记得 5 次对 0 次，判为模板 7 次对 12 次。已上线 |
| 工作室用同样的流程 | 由工作室的总监启动三个概念智能体 | 获奖对照题上创意分 +1.6、总分 +2.5，新题上分别为 +2.3 和 +3.1 |
| 交付前的评审 | 网站能用之后，启动一个不带上下文的评审，像 Awwwards 评审团那样根据截图和一次访客试用来评判它，指出代价最大的十个缺陷；团队修好后，再由第二个评审来评 | 总分 +1.13，10 次评阅中 10 次领先（符号检验 p 0.002）；花费约为 1.6 倍。已上线 |

其中两项值得作为发现说明。独立的头脑解决的是*创意*雷同，不是创意落在哪里：
做出来的页面把创意放进了模板式首屏下面的某个板块；
对搭建者说“首屏就是创意”，它只在字面上照做（在主视觉的角落放一个小滑块）。
真正把创意搬上首屏的，是把原型当作产物来复用。

### 没有打动评委的改法

下面每一项都是在已上线流程上只改一处，五道题每题做两个作品，在同一轮里与同一个对照组一起盲评：

| 改法 | 总分（与对照组相比） | 备注 |
| --- | --- | --- |
| 让主体的物件贯穿页面的每个部分 | 约 0 | |
| 不停在第一个创意上，继续往下想 | +0.34，两轮合起来约为 0 | 最好的作品分数更高，最差的更低 |
| 用代码擅长的风格来呈现（渲染出来像玩具时，把物件画成图版或线描） | +0.49 | 它针对的设计分几乎没动 |
| 由评审而不是搭建者在三个原型中挑选 | +0.43，第二次运行为 +0.34 | 20 次评阅中 9 次领先；一周后还记得、当日最佳都有上升；未得到证实 |
| 增加第四个概念智能体，把两个真实事实结合起来 | -0.21 | 没有一个网站是从它长出来的 |
| 评审从上到下看每一屏 | -0.57 | 开头部分该修的没有修 |
| 后面几屏由独立的智能体分别做原型 | -0.30 | |
| 展示文字用 SVG 绘制字形 | +0.05 | |
| 招牌瞬间永不结束 | -0.23 | |
| 用手势把主体变成它自身的另一个真实版本 | -0.18 | |
| 每一屏按跨页排版，而不是按组件 | +0.02 | |
| 首屏回应掠过的指针（附带浏览器检查） | -0.08 | 指针引起的变化从屏幕的 0.6% 升到 14.6%；分数没有变化 |
| 以上其中三项一起用 | -0.58 | |
| 题目中允许使用开放许可的字体 | +0.20 | 设计分 +0.3；“默认字体”这条批评从占评语的 55% 降到 0% |
| 评审一轮接一轮，直到没有评审指出代价超过半分的缺陷（最多四轮） | +0.01 | 它的作品被指出的底线缺陷更多，而不是更少 |
| 原型做到约三屏，把两个内容块放进创意自己的容器里 | -0.02 | 被判为模板的比例更低（50% 对 65%）；分数持平 |

加进技能里的浏览器页面检查（横向滚动、文字过小、对比度、文字被截断、脚本错误）作为工作室 2.5 版上线，
在工作组题单上与 2.1 版持平，后来又撤掉了：智能体在 24 次试验中只运行过它 1 次。

### 评委的评分表说了什么

在 420 次评阅中（第 16 至 22 轮）：

- **题目决定上限**。得分在 30 分（满分 40）及以上的评阅占比：数据库发布 23%，舞蹈节 11%，面包店 4%，越野品牌 2%，
  赛车手 0%。代码画得好的东西（仪表、纸质记录、光、字体）能到 30 分；汽车、头盔、人脸和面包停在 28 分附近。
- **多数作品仍然是模板**。每个实验组都有 60% 到 95% 的评阅这样判定；被判为非模板的作品高 0.8 分。
- **创意从哪里来，有一点影响**。从主体的数据或媒介出发的那个概念智能体所长出的作品，在 43% 的评阅中没有通过移植测试；
  从主体的物件或名字出发的，这一比例是 2%；总分相差约 0.3。
- **评语点出了什么**。“首屏以下又回到了常规板块”：占评语的 34%，大多出现在较好的作品上。
  “这个创意适用于这一类别的任何品牌”：14%，分数约低一分。
  “字体像系统默认字体”：17%（11 月 27 日之前，题目禁止使用网络字体）。“渲染得像玩具”：9%。
- **在赛车手这道题上，几乎每个作品都在重现那条随每场胜利变宽的头盔条纹**，每个实验组都是如此：
  题目里最醒目的事实赢得了挑选。获奖网站的创意是让访客把车手自己的头盔图案擦到他的脸上，这需要他的照片。

### 测量有多精确

- 两位评委评同一个作品，平均相差 0.72 分（满分 40）；
  同一实验组在同一道题上的两个作品相差 1.41 分（单个作品的标准差约为 1.2）。
  因此，一个实验组十个作品的均值，标准误约为 0.4；两个各有十个新做作品的实验组，
  要相差约 1.1 分才能拉开两个标准误（二十个作品时为 0.8，四十个时为 0.5）。
- 有一段时间，每个实验组都和同样的十个对照作品比较。这些作品恰好在一道题上偏弱、在另一道题上偏强：
  每个实验组在数据库这道题上，24 次评阅中有 22 次“赢”；在舞蹈节这道题上，24 次中有 20 次“输”。
  从第 24 轮起，对照组每一轮都重新做。
- 所以，上面那些与对照组相差约半分以内的改法，与噪声无法区分；而真实有效的那两项，变化要大得多。

## 11 月 27 日的现状

- 流程在每项标准约 7.1 分处进入了平台期。加入评审这一步之后，每个改法在这套测量的分辨率内都测得为零；
  修掉一个被点名的缺陷（首屏回应掠过的指针）也没有改变分数：评委点名的缺陷随整体水平一起变化。
- 团队内部的 GPT 评审看不到评委看到的东西：用了四轮评审后，被指出的底线缺陷更多了，而不是更少。
- 评测现在和真实使用一样，允许使用开放许可的字体；这个场景仍然没有图像或视频模型。
- 两个从外部引入品味的改法正在新题上运行，各做十二个作品，对比已上线流程的十二个作品：
  领队在概念步骤之前研究六个近期获奖网站，并把笔记传下去；
  或者构思时不看任何外部网站，而每个评审先看四个其他类别获奖网站的截图，再把我们的作品放在它们旁边来评。
- 工作室发布到目录还要等它的题单：2.3 和 2.4 版的题单均值都从 0.667 降到了 0.583，
  原因都是有一道题在两次试验中只通过了一次，而 2.1 版的记录里这道题只有一次试验且通过了；加上门槛的均值规则很严格。

## 我们的结论

1. 创意来自独立的头脑时会变好，复用产物时才会落到页面上；描述模板的文字挡不住模板。
2. 选择是薄弱的一步：团队守着题目里最醒目的事实或常规的方向。来自团队之外的一句话选择，比几轮意见更能推动作品。
3. 每个实验组十个作品时，价值不到约一分的单项改动无法与噪声区分。
   要与同一轮里新做的对照作品比较，并按一个改法究竟能不能带来一分的变化来筛选改法。
4. 我们碰到的上限是模型自身的品味；剩下要试的，是把它缺少的东西引进来。
